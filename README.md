# Machine Learning :
Machine Learning is field of computer science which uses statistical technique to give the computer system ability to learn with "data" without being explicitly programmed.
In simple words, ML means "learning from data" and it does not require explicit programming.
In ML, we gives data to system and then system analyze the data and finds patterns.
ML works good for small data.

Example : Checking the email is spam or not.

# Types of Machine Learning:
There are mainly 4 types of Machine Learning:

```bash
1. Supervised Learning

2. Unsupervised Learning

3. Semi-Supervised Learning

4. Reinforcement Learning

```

# 1. Supervised Learning :
It is a type of ML where we have a dataset which contains input and output and on the basis of input and output and we need to make the prediction on the new input by identifying the relationship between input and output.
Most of the time, we works on supervised machine learning.

<b>simple analogy to understand supervised learning :</b>

```bash
It is like learning with a teacher.

The teacher provides:

Questions
Correct answers

The student learns from them and solves new questions later.

```

In simple words we can say that Supervised learning is a type of machine learning in which model learns using labeled data. Labeled data means Input data is given and Correct output (answer) is also given.
<br>
The machine learns the relationship between input and output and then predicts answers for new data.

It is further divided into two types :

(I) Regression :

When we have a dataset which contains input and output but the type of output is numeric.
Example : Suppose we have a dataset which has three columns where first 2 columns are input and third column is output. First column is "IQ", second column is "CGPA" and third column is "Placement Package".

(II) Classfication :

When we have a dataset which contains input and output but the type of output is categorical. example: Gender,Nationality etc.
Example : Suppose we have a dataset which has three columns where first 2 columns are input and third column is output in which first column is "IQ", second column is "CGPA" and third column is "Placement" (in terms of "YES/NO").

# 2. Unsupervised Learning:
It is a type of ML where we have dataset that contains only input and we need to get some useful information by using different technique.
<br>
In Simple words we can say that Unsupervised Learning is a type of machine learning where the model learns from unlabeled data.

There are no correct answers provided.

The machine tries to:

Find hidden patterns,
Group similar data,
Discover relationship

<b>>simple example to understand supervised learning :</b>

```bash
It is like a student learning without a teacher.

The student observes things and finds patterns on their own.

```
